# solid-store-tools

Reactive object utilities for [SolidJS](https://www.solidjs.com/).

## Install

```sh
npm install solid-store-tools solid-js
```

## Usage

All public APIs are available from the package root:

```ts
import { merge, omit, pick, switchStore } from 'solid-store-tools'
```

The package includes utilities for deriving, filtering, merging, observing, and switching reactive objects and stores.
